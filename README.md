# Ace Place — website

Статический русско-корейский сайт. Все файлы для размещения находятся в `dist/`; сборка и npm не нужны.

Локальный просмотр из этой папки:

```powershell
node preview.mjs
```

Откройте http://localhost:4173.

## Редактирование

`dist/config.js` — публичные данные сайта: цена, вместимость, время аренды, адрес, контакты и ссылка бронирования. Для переводимых значений заполняйте `ru` и `ko`. Отсутствующие значения отображаются как «По запросу» / «По согласованию»; отсутствующие контакты не создают пустых ссылок. `bookingUrl` должен быть полным HTTPS-адресом; без него кнопка ведёт к контактам, без имитации отправки заявки.

Исходный `../config.yaml` и конфигурация бота сохранены без изменений. Они содержат данные для другой локации, поэтому не выгружаются в браузер. Не помещайте секреты в `dist/`.

`dist/app.js` — русские и корейские тексты. `dist/style.css` — оформление и адаптация. `dist/assets/` — фотографии из исходного проекта; перед использованием для ереванской локации подтвердите их актуальность или замените. Встроенная карта ищет предоставленный адрес; внешняя кнопка открывает Google Maps. Google Maps и веб-шрифты требуют доступа к интернету; предусмотрены системные шрифты.

Для хостинга используйте каталог `dist`. Настройки Sites находятся в `.openai/hosting.json`.
